## O que é o Zettelkasten?

É um método de estudos que consiste na criação de uma "rede" de conhecimentos.
Aqui é abandonado o conceito tradicional de pastas, onde cada tópico de estudo era divido em pastas separadas para o tópico em si.

Dentro do Zettelkasten, são usados três tipos diferentes de anotações ou notas, as "Fugazes", "de literatura" e "Permanentes"

- **Fugazes**: Notas temporárias apenas para registrar informações estudadas. Elas são ideias isoladas, escritas apenas para anotar uma ideia ou como um lembrete para depois.

- **Literatura**: são ideias extraídas de livros, artigos ou até mesmo de vídeos. São breves e devem ser escritas com as próprias palavras.

- **Permanentes**: Notas únicas, onde é escrito o aprendizado tirado das notas de literatura e do material estudado. Vai aqui o desenvolvimento da ideia das notas de literatura, sendo uma espécie de "conclusão" à tal assunto
## Como funciona

Dentro do ecossistema do meu Obsidian, implementei o funcionamento dele da seguinte forma:

1. Notas para Aprofundar
	- Aqui vão as notas temporárias mencionadas acima. Notas cujo objetivo é apenas marcar ou registrar pontos que serão mais explorados futuramente
2. Material de Origem
	- Aqui vão as notas de literatura, notas onde é registrado sua origem. Aqui é armazenados os links dos materiais originais para futuras consultas
3. Tags
	- Aqui são notas que funcionam como tags para serem anexadas nas notas da aba "Notas Principais"
4. Indexes
	- Indexes servem para quando uma tag especifica for usada diversas vezes, funciona para visualizar quantas notas foram anexadas à ela
5. Modelos
	- Templates para serem usados em notas da aba "Notas Principais"
6. Notas Principais
	- Aqui é onde são criadas as notas "Permanentes", ou seja, é onde é desenvolvido o conteúdo de uma temporária
